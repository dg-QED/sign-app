# Sign

iPad PDF signing app. Open https://dg-qed.github.io/sign-app/ in Safari, then Share → Add to Home Screen.

Signatures sync from the private repo dg-QED/signatures (folder `signatures/`). The GitHub token is entered in the app on the iPad and never stored here.

`src/` holds the source; `node src/build.mjs` (run from a folder with the npm deps) regenerates index.html.
